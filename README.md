# Shree Krishna Resort

Website for Shree Krishna Resort, Hiranvel (Sasan Gir), Gujarat. Static HTML, no build step.

- `index.html` is the home page (desktop and mobile layouts).
- `couple-room.html`, `cottage-room.html`, `family-room.html` are the room pages with photo galleries.
- `assets/` holds photos and videos.

Bookings go to WhatsApp (+91 97242 08027). To publish with GitHub Pages: Settings, Pages, deploy from branch `main`, folder `/ (root)`.
